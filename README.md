# Mistiremariam Girma – Personal Portfolio Website

This repository contains the **personal portfolio website** of Mistiremariam Girma, showcasing her projects, certificates, leadership experiences, writing, and volunteering activities. The website highlights achievements in engineering, space science, sustainability, technology, and advocacy.

## Website Structure

portfolio/
├── index.html # Home page
├── about/ # About Me section
│ └── about.html
├── certificates/ # Certificates & achievements
│ └── certificates.html
├── projects/ # Highlighted projects and initiatives
│ └── projects.html
├── contact/ # Contact form/page
│ └── contact.html
├── css/ # Stylesheets
│ └── style.css
├── images/ # Images used across the website
└── README.md # This file

## Features

- **Home Page:** Introduction and overview of portfolio.
- **About Page:** Personal background, education, and interests.
- **Certificates Page:** Display of professional and academic certificates.
- **Projects Page:** Filterable showcase of projects, activities, volunteering, and tech initiatives. Includes slideshows for multi-image projects.
- **Contact Page:** Simple form for reaching out directly.
- **Responsive Design:** Fully responsive across desktop, tablet, and mobile devices.
- **Interactive Filters:** JavaScript-based project filtering by categories (Engineering, Space, Sustainability, Leadership, Volunteering, Writing, Tech).

## Technologies Used

- **HTML5 & CSS3**
- **JavaScript** for dynamic filtering
- **Font Awesome** for icons
- Optional: Custom fonts or images in `images/`
